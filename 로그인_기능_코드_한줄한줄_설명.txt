1. SecurityConfig.java 코드 설명:
package org.zerock.board.config;
- 이 클래스가 속한 패키지 선언
- config 패키지는 설정 관련 클래스들을 모아둔 곳

import org.springframework.context.annotation.Bean;
- Spring의 Bean 어노테이션을 import
- 빈 객체를 생성하고 관리하기 위해 사용

import org.springframework.context.annotation.Configuration;
- Spring의 Configuration 어노테이션을 import
- 설정 클래스임을 나타냄

import org.springframework.security.config.annotation.web.configuration.EnableWebSecurity;
- Spring Security의 웹 보안 활성화 어노테이션 import
- 웹 보안 기능을 사용하기 위해 필요

@Configuration
- 이 클래스가 Spring 설정 클래스임을 나타냄
- 빈 정의와 설정을 포함

@EnableWebSecurity
- Spring Security의 웹 보안 기능을 활성화
- 웹 요청에 대한 보안 처리 가능

@Bean
public BCryptPasswordEncoder bCryptPasswordEncoder()
- 비밀번호 암호화를 위한 빈 등록
- BCrypt 알고리즘을 사용한 비밀번호 암호화 제공
- 단방향 해시 함수로 비밀번호를 안전하게 저장

@Bean
public SecurityFilterChain filterChain(HttpSecurity http)
- 보안 필터 체인 설정 메서드
- HTTP 보안 관련 설정을 담당

http.authorizeHttpRequests((auth) -> auth
- HTTP 요청에 대한 권한 설정 시작
- URL별 접근 권한을 정의

.requestMatchers("/", "/login", "/loginProc", "/join", "/joinProc").permitAll()
- 지정된 URL들은 모든 사용자가 접근 가능
- 로그인, 회원가입 등 인증이 필요 없는 페이지

.requestMatchers("/admin").hasRole("ADMIN")
- /admin URL은 ADMIN 권한이 있는 사용자만 접근 가능
- 권한 기반 접근 제어

.requestMatchers("/board/**").hasAnyRole("USER")
- /board로 시작하는 모든 URL은 USER 권한이 있는 사용자만 접근 가능
- 게시판 관련 기능은 로그인한 사용자만 사용 가능

http.formLogin((auth) -> auth.loginPage("/login")
- 로그인 관련 설정 시작
- 커스텀 로그인 페이지 설정

.loginProcessingUrl("/loginProc")
- 로그인 처리를 담당하는 URL 설정
- Spring Security가 이 URL로 전송된 로그인 정보를 처리

.defaultSuccessUrl("/board/list", true)
- 로그인 성공 시 이동할 기본 URL 설정
- true: 항상 이 URL로 이동

http.logout((auth) -> auth.logoutUrl("/logout")
- 로그아웃 관련 설정
- 로그아웃 처리를 담당하는 URL 설정

.logoutSuccessUrl("/"))
- 로그아웃 성공 시 이동할 URL 설정
- 메인 페이지("/")로 이동

http.csrf(AbstractHttpConfigurer::disable)
- CSRF 보호 기능 비활성화
- 개발 단계에서 테스트를 위해 비활성화

http.sessionManagement((auth) -> auth
- 세션 관리 설정 시작
- 세션 관련 보안 설정

.maximumSessions(1)
- 한 사용자의 최대 세션 수를 1로 제한
- 동시 로그인 방지

.maxSessionsPreventsLogin(true))
- 최대 세션 수 초과 시 새로운 로그인 방지
- 기존 세션이 유지됨

import org.springframework.security.core.userdetails.UserDetailsService;

import org.springframework.security.core.userdetails.UsernameNotFoundException;

import org.springframework.stereotype.Service;

import org.zerock.board.entity.Member;

import org.zerock.board.repository.MemberRepository;

@Service
- 이 클래스가 서비스 계층의 컴포넌트임을 나타냄
- Spring의 서비스 빈으로 등록

@RequiredArgsConstructor
- final 필드에 대한 생성자를 자동으로 생성
- 의존성 주입을 위해 사용

@Log4j2
- 로깅을 위한 Log4j2 어노테이션
- 로그 출력 기능 제공

public class CustomUserDetailsService implements UserDetailsService
- Spring Security의 UserDetailsService 인터페이스 구현
- 사용자 인증을 처리하는 서비스 클래스

private final MemberRepository memberRepository
- 회원 정보를 조회하기 위한 레포지토리 주입
- final: 생성자 주입을 통한 불변성 보장

@Override
public UserDetails loadUserByUsername(String username) throws UsernameNotFoundException
- 사용자 이름으로 사용자 정보를 조회하는 메서드
- Spring Security가 호출하는 핵심 메서드
- UsernameNotFoundException을 던질 수 있음

Member userData = memberRepository.findByUsername(username)
- DB에서 사용자 이름으로 회원 정보 조회
- Member 엔티티 객체 반환

if (userData == null)
- 조회된 회원 정보가 없는 경우
- 사용자가 존재하지 않는 경우

throw new UsernameNotFoundException("User not found with username: " + username)
- 사용자가 없을 때 예외 발생
- 사용자 이름을 포함한 에러 메시지 전달
- Spring Security에 사용자 없음을 알림

return new CustomUserDetails(userData)
- 조회된 회원 정보를 CustomUserDetails 객체로 변환
- Spring Security가 이해할 수 있는 형태로 반환

3. CustomUserDetails.java 코드 설명:
public class CustomUserDetails implements UserDetails
- Spring Security의 UserDetails 인터페이스 구현
- 사용자 정보를 Spring Security가 이해할 수 있는 형태로 제공

private Member member
- 실제 회원 정보를 저장하는 필드
- Member 엔티티의 모든 정보를 보관

public CustomUserDetails(Member member)
- 생성자에서 Member 엔티티를 받아 초기화
- 사용자 정보를 저장

@Override
public Collection<? extends GrantedAuthority> getAuthorities()
- 사용자의 권한 정보를 반환하는 메서드
- 권한 기반 접근 제어에 사용

Collection<GrantedAuthority> collection = new ArrayList<>()
- 권한 정보를 담을 컬렉션 생성
- GrantedAuthority 인터페이스 구현체 사용

collection.add((GrantedAuthority) () -> member.getRole())
- 회원의 권한 정보를 컬렉션에 추가
- 람다식을 사용하여 권한 정보 제공

@Override
public String getPassword()
- 사용자의 암호화된 비밀번호를 반환
- Spring Security가 비밀번호 검증에 사용

@Override
public String getUsername()
- 사용자의 아이디를 반환
- 로그인에 사용된 아이디

@Override
public boolean isAccountNonExpired()
- 계정이 만료되지 않았는지 확인
- true: 계정이 유효함

@Override
public boolean isAccountNonLocked()
- 계정이 잠겨있지 않은지 확인
- true: 계정이 잠겨있지 않음

@Override
public boolean isCredentialsNonExpired()
- 비밀번호가 만료되지 않았는지 확인
- true: 비밀번호가 유효함

@Override
public boolean isEnabled()
- 계정이 활성화되어 있는지 확인
- true: 계정이 활성화됨
