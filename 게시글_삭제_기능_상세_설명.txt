게시글 삭제 기능 상세 설명
===========================

[관련 파일 목록]
주요 파일:
- BoardController.java: 컨트롤러
- BoardService.java: 서비스
- BoardRepository.java: 레포지토리
- ReplyRepository.java: 댓글 레포지토리
- Board.java: 엔티티

연관 파일:
- read.html: 삭제 버튼이 있는 화면
- Reply.java: 댓글 엔티티
- application.properties: 설정 파일

1. BoardController.java의 게시글 삭제 처리:
@PostMapping("/remove")
- POST 방식으로 "/board/remove" URL에 접근 시 실행
- 게시글 삭제를 처리

public String remove(long bno, RedirectAttributes redirectAttributes)
- 게시글 삭제 처리 메서드
- bno: 삭제할 게시글 번호
- RedirectAttributes: 리다이렉트 시 데이터 전달용

log.info("bno: " + bno)
- 삭제하려는 게시글 번호를 로그로 출력
- 디버깅 목적의 로그 기록

boardService.removeWithReplies(bno)
- 게시글과 관련된 댓글들을 함께 삭제
- 댓글이 있는 게시글도 안전하게 삭제

redirectAttributes.addFlashAttribute("msg", bno)
- 삭제 완료 메시지를 리다이렉트 시 전달
- 일회성 데이터로 전달됨

return "redirect:/board/list"
- 삭제 완료 후 목록 페이지로 리다이렉트

2. BoardService.java의 게시글 삭제 처리:
public void removeWithReplies(Long bno)
- 게시글과 댓글을 함께 삭제하는 메서드
- bno: 삭제할 게시글 번호

replyRepository.deleteByBoard_Bno(bno)
- 게시글에 달린 댓글들을 먼저 삭제
- 댓글 삭제 후 게시글 삭제

boardRepository.deleteById(bno)
- 게시글을 데이터베이스에서 삭제
- JPA Repository의 deleteById 메서드 호출

3. BoardRepository.java의 삭제 관련 처리:
@Query("select b, w from Board b left join b.writer w where b.bno=:bno")
- 게시글과 작성자 정보를 함께 조회하는 쿼리
- 삭제 권한 확인을 위해 작성자 정보 필요

Object getBoardWithWriter(@Param("bno") Long bno)
- 게시글 번호로 게시글과 작성자 정보 조회
- @Param: JPQL의 파라미터 바인딩

4. ReplyRepository.java의 댓글 삭제 처리:
void deleteByBoard_Bno(Long bno)
- 게시글 번호로 관련 댓글들을 삭제하는 메서드
- 게시글 삭제 전에 호출됨

5. 관련 파일 및 참고사항:
- read.html
  - 게시글 삭제 버튼
  - 삭제 확인 다이얼로그
  - CSRF 토큰 포함

- BoardDTO.java
  - 게시글 정보 전달 객체
  - 삭제할 게시글 번호 포함

- Reply.java
  - 댓글 엔티티
  - 게시글과 연관 관계
  - 게시글 삭제 시 함께 삭제

- application.properties
  - 데이터베이스 연결 설정
  - JPA 설정
  - 로깅 설정

6. 삭제 처리 시 주의사항:
- 댓글이 있는 게시글 삭제 시 댓글도 함께 삭제
- 삭제 전 작성자 확인 필요
- 트랜잭션 처리로 데이터 정합성 보장
- 삭제 후 목록 페이지로 리다이렉트
- 삭제 완료 메시지 표시
